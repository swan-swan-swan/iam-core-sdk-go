# MFA 认证上下文 Go SDK 实施计划

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development for every implementation task and superpowers:verification-before-completion before claiming completion.

**Goal:** 让 IAM Core Go SDK 从已验证的 ID Token 安全解析 auth_time/amr，并在 AuthContext、BFF callback、refresh 和 session adapters 中无损保留。

**Architecture:** core verifier 负责标准 claim 解析与规范化；AuthContext 是跨 runtime/adapters 的公共载体；BFF callback 以 ID Token 为 MFA 上下文权威，refresh 明确实施“新 ID Token 一致或沿用旧值”策略；session conformance suite 防止 adapter 丢字段。

**Tech Stack:** Go 1.24+、golang-jwt/jwt、OIDC runtime、BFF runtime、memory/Redis session adapters。

**Frozen source:** docs/superpowers/specs/2026-09-17-totp-2fa-sdk-design.md.

**Dependency:** iam-core-server 冻结 ID Token auth_time/amr 契约；SDK 不依赖服务端实现提交即可按契约开发。
